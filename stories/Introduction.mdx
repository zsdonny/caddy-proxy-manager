## How mocking works

Stories replace `window.fetch` via Storybook's `beforeEach` hook (runs synchronously before render, guaranteeing the mock is in place before any `useEffect` fires).

`"use server"` action files are replaced at the Vite transform layer with no-op stubs, so `node:fs`, `better-sqlite3`, and `next/server` never enter the browser bundle.

## Dark / Light mode

Use the **contrast toolbar button** (**&#9681;**) at the top of the page to toggle between light and dark mode. The toggle is wired to Tailwind's `dark` class so every CSS variable flips correctly.
